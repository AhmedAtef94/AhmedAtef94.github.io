# Ahmed Atef | Portfolio 👨‍💻

Personal portfolio of **Ahmed Atef**, Project Manager in EdTech with a Front-End Development background.

🔗 **Live site:** https://ahmedatef94.github.io/

Here you can see my projects, experience and contact information. If you have a project in mind, fill in the contact form and I'll reply as soon as I receive your message.

## 📝 Features

- Light/Dark mode ☀ 🌙
- Mobile first design 📱
- Responsive design ↔
- Contact me form 📎
- Form validations ✔
- Simple CSS animations 💥
- My projects carousel
